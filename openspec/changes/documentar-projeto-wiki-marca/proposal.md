# Proposal

## Why

O README atual reúne muitas informações em um único texto e não oferece um caminho de estudo progressivo para quem quer entender o objetivo, a metodologia e os limites das medições do IAMonitor. A documentação pública precisa refletir a identidade visual do canal Dev Terceira Idade e ser navegável no repositório e no Wiki.

## What Changes

- Organizar a documentação em páginas temáticas, com início rápido, leitura da bancada, metodologia dos tokens, cache, artefatos, dados, exportações, arquitetura e solução de problemas.
- Aplicar as cores, o logotipo e a assinatura do kit de marca do canal, preservando créditos e origem dos arquivos visuais.
- Reformular o README como porta de entrada para as páginas e publicar uma cópia navegável no GitHub Wiki.
- Conferir links, exemplos, limites da medição e publicação, sem incluir sessões pessoais, credenciais ou conteúdo de `data/`.

## Capabilities

### New Capabilities

Nenhuma. Esta mudança documenta o comportamento existente; não altera requisitos do aplicativo.

### Modified Capabilities

Nenhuma.

## Impact

Arquivos de documentação no repositório, ativos visuais em `docs/assets/`, README e configuração/publicação do Wiki no GitHub. Nenhuma classe Java, API ou esquema SQLite muda. O conteúdo do Wiki deve derivar dos mesmos arquivos versionados no repositório.
